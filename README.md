# SQL Interview Practice – Real Business Analyst Workflow

This project demonstrates practical SQL interview preparation using Python, SQLite, and Jupyter Notebook through realistic business-focused questions.

Instead of memorising isolated SQL syntax, the focus of this project is understanding how SQL is actually used in Data Analyst and Business Analyst workflows.

---

# Workflow Overview

The workflow followed in this project:

1. Importing datasets using Pandas
2. Exploring and understanding the data
3. Creating a SQLite database connection
4. Converting DataFrames into SQL tables
5. Running SQL queries inside Jupyter Notebook
6. Solving realistic business questions using SQL
7. Interpreting results like a Data Analyst
